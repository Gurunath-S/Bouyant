# Web Interface Guidelines

1. **Accessibility**: Maintain WCAG AA contrast, proper aria attributes, semantic heading structure (H1 -> H2 -> H3), readable font sizes (minimum 12px for micro copy, 14px-16px for body).
2. **Responsive Grids**: Flexbox and CSS Grid layouts (`grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`) to ensure fluid responsiveness on all viewport sizes from mobile to wide desktop.
3. **Interactive Touch Targets**: Buttons and clickable elements maintain minimum touch target dimensions, hover elevation feedback, and active click scaling.
4. **Visual Hierarchy & Rhythm**: Consistent spacing scale (4px/8px grid system), clear distinction between primary actions, secondary outlines, and tertiary text triggers.
